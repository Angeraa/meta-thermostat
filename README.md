# Personal Thermostat

This project is intended to be a crack at creating my own personal smart home thermostat built using the yocto project and running on a Raspberry Pi 5.

### Current implementation v0.1

v0.1 will add the UI functionality to the thermostat to have many screens and ways to interact with the thermostat state via a UI

### Plans

Plans include keeping app state persistent between power cycles, the ability to add external sensors made using the same bme680 sensor and a wireless capable esp32, a more advanced algorithm to control the heating and cooling with smart vent control, and the ability to control multiple heating systems at once like an underfloor heater and a regular furnace at the same time.
